# Slide 6: How It Works (Cara Kerja)

---

## 🎯 Tujuan Slide
Memberikan deskripsi operasional tingkat tinggi yang jelas mengenai alur produk dan teknologi yang menggerakkan platform Anda.

## 📝 Konten Utama (InnerWhisper: Automated Career Copilot)
* **3 Langkah Sederhana Perjalanan User:**
  1. **Asesmen Mandiri Gratis (Self-Assessment):** User mengerjakan tes minat bakat 25 pertanyaan psikometri atau mengunggah resume ke CV ATS Scanner secara instan tanpa biaya.
  2. **Dapatkan Diagnostik & Rekomendasi:** Sistem langsung memetakan kekuatan minat dan memberikan checklist skor kelayakan resume secara real-time.
  3. **Buka Laporan Mendalam (Instant Digital Unlock):** Untuk kebutuhan melamar kerja tingkat lanjut, user dapat membuka laporan PDF komprehensif atau simulator wawancara metode STAR mulai Rp 19.000 dengan aktivasi otomatis instan via QRIS/E-Wallet.

---

## 🗣️ Poin Penjelasan (Narasi Presentasi)
> *"Bagaimana alur ini berjalan? Sangat cepat dan tanpa hambatan. Pertama, user dapat langsung mencoba tes minat atau mengaudit teks CV mereka secara cuma-cuma dalam hitungan menit. Begitu mereka melihat hasilnya, sistem memberikan umpan balik awal. Ketika user ingin melangkah lebih jauh—seperti mengunduh Laporan Diagnostik Karier Lengkap atau menguji respons wawancara mereka—mereka dapat membuka fitur berbayar tersebut secara instan melalui pembayaran QRIS otomatis. Tidak ada antrean, tidak ada birokrasi, semua otomatis aktif detik itu juga."*
